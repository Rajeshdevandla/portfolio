# Rajesh Kumar — Developer Portfolio

A responsive personal portfolio showcasing my full-stack Java, cloud, and AI engineering work.

## Highlights

- Full-stack experience with Java, Spring Boot, React, and Angular
- Cloud-native development with AWS, Docker, and Kubernetes
- Microservices, REST APIs, Kafka, and relational databases
- Interactive project, skills, experience, and contact sections
- Responsive design with animated backgrounds and scroll-reveal effects

## Built With

- React 19
- Create React App
- CSS
- HTML Canvas
- GitHub Pages-ready static build

## Run Locally

```bash
git clone https://github.com/Rajeshdevandla/portfolio.git
cd portfolio
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Production Build

```bash
npm run build
```

The optimized site will be generated in the `build/` directory.
